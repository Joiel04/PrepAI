# PrepAI

PrepAI is an AI-powered interview preparation platform designed to help users practice job interviews and improve their interview performance through AI-generated questions and feedback.

## Tech Stack

- Next.js
- React
- JavaScript
- Tailwind CSS
- Node.js
- Express.js
- MongoDB
- Mongoose

## Planned Features

- User authentication (Sign Up / Login)
- Personalized interview setup
- AI-generated interview questions
- AI-powered answer evaluation
- Interview feedback and results
- Interview history and dashboard
- Resume-based interview preparation
- Voice-based AI interviews

## Project Status

🚧 **Under Development**

PrepAI is currently being built from scratch. Features will be added progressively as development continues.
